# Skill-Gap-Analysis-Agent-Project
Domain: Generative AI | Large Language Models (LLMs) | Retrieval-Augmented Generation (RAG) | AI Agents
Description: Developed an AI-powered Skill Gap Analysis system using LangChain and LangGraph to evaluate candidate profiles against job descriptions. Utilized PDF document processing, RAG-based retrieval, and LLM-powered analysis to identify matching and missing skills, calculate skill gap percentages, and generate personalized recommendations to improve employability and career readiness. 
Technologies: Python, LangChain, LangGraph, OpenAI 
Tools & Frameworks: FAISS, OpenAI Embeddings, PyPDFLoader, Jupyter Notebook 
Techniques: RAG, Semantic Search, PDF Processing, Prompt Engineering, LLM-based Analysis, AI Agent Workflows
